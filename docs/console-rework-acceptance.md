# 主服务交互重整验收标准（2026-10-08）

来源：用户实际体验反馈。本文是验收标准，不代表各项已经通过。

## 信息架构
- 顶部直接展示聊天、资产、定制任务、Skills、记忆、文档、日志等主要入口，不再套“控制台”父导航。
- 资产替代旧总览，本机和生命周期操作纳入资产；旧入口不能仅被隐藏而造成必要操作不可达。
- 角色在聊天新建/头像卡片编辑，渠道配置归角色；审批和不确定任务处置在聊天完成。
- 任务、告警、触发、审计、输出合并日志，来源颜色加文字标签，不仅依赖颜色。

## 资产与健康
- 区分Agent心跳、SSH可达检测、本机执行环境活性。不能拿配置存在等同健康；无遥测显示未知而非伪造绿灯。
- 心跳记录默认保留24小时。最近10个预期心跳窗口统计送达数/未达率，有不足样本提示；这不是TCP/IP网络丢包率。
- 其他主服务占用与本主服务真正有任务等待分别体现；空闲/失联后不残留错误等待灯。
- 本机的执行边界说明清楚：容器部署里的local通常是控制服务容器，不默认等同宿主机权限。

## 聊天与权限
- 默认confirm逐条审批，所有命令（自然包括写操作）未经批准不可执行；不假装能可靠自动识别任意shell的读写危险性。
- readonly不只是提示词：不暴露执行工具，强行伪造执行调用也由服务端拒绝；这意味着不运行只读shell，不是任意shell只读沙箱。
- direct明确说明跳过审批，但仍不能突破执行账号和资产允许账号范围。
- 任务步骤执行中可见、完成折叠、可重新展开。刷新不丢状态，不能把proposed画成已成功。
- unknown人工确认保留任务ID、说明及结果选择；租约过期只观测，不自动重派、不冒充结果已知。

## 知识、Skills与通知
- 注册资产的核心列表文档由真实资产数据派生，不能出现第二套可编辑资产真相；权限范围与密钥脱敏一致。
- Skills按书签式卡片展示角色绑定及启用状态；未绑定角色不得通过上下文或检索使用。
- 定制任务可配置结果Webhook；关闭只留聊天、开启才外推。原部署配置保持明确兼容路径。
- 保留Webhook SSRF、脱敏、持久化与去重；日志页不能泄露目标URL中的凭据。

## 验证与交付口径
- 验证静态资源、API鉴权、后端回归、前端语法及可行的真实浏览器交互。
- 本地完成、浏览器验证、发布、部署、真机验证是不同状态，交付报告须分别说明。
- 不能用旧CI通过、截图或合成测试冒充此次生产环境已验证。
