# 资产记忆与导航（2026-10-09）

## 记忆归属
- 资产卡“记忆”读取/编辑 `/api/v1/assets/{asset_id}/memory`；SQLite `asset_memory.asset_id` 主键+资产外键，每资产最多一份，不再以角色ID冒充资产ID。未编辑的资产返回空记录revision=0，GET不造数据。注销保留记忆，彻底删除随资产删除，既有claimed/unknown保护不变。
- PUT管理员认证，content最多20,000字符，expected_revision必填，冲突409（重新打开后编辑），支持清空；审计只记修订和长度，不复制全文。列表 `/api/v1/asset-memories?limit=50&offset=0` 只给元数据、total和next_offset；limit 1–100。
- 模型工具 `read_asset_memory({asset_id})` 只读精确ID的活动资产记忆，返回ID、全文、修订、来源；不存在/非法ID返回工具错误。只读模式也能读，但不能执行命令。不是将所有资产全文注入每轮，避免50节点上下文膨胀；该工具结果是普通不可信参考数据，不授予权限。
- **本轮不自动更新资产记忆。** 角色对话可能跨资产，不能根据自然语言猜归属。管理员负责维护；未来自动归档须以实际任务asset_id和可验证来源为依据。本轮没有将旧角色记忆迁入资产，也不声称模型已自动保存。
- 原role_memory、记忆worker、角色对话连续性原样保留；资产页下方“旧角色记忆（兼容保留）”是延迟打开的兼容入口，明确不是资产记忆。无新多租户/RBAC承诺，仍是全局管理员信任域。

## 界面
顶栏顺序：聊天、资产、Skills、文档、日志、定制任务。无记忆顶栏，首次默认聊天；sessionStorage仅记视图，旧memory映射资产。帮助图标支持悬停/焦点、点击固定/收起、Escape、aria-label和expanded。资产危险区底部右对齐，与编辑/连接/记忆分离，恢复仍在普通区。角色列表无刷新按钮；初次、编辑后及30秒受控后台更新；选项在textarea前，confirm默认不变。

## 加载与隐私
- 首页和旧固定静态URL no-store；准确指纹URL JS/CSS public,max-age=31536000,immutable；不存在指纹404。无用户数据进入静态文件或Service Worker。
- Token仅内存；缓存仅本标签页内存，锁定/新登录generation隔离，取消未完成请求并拒绝迟到结果。缓存JSON克隆，防渲染修改共享对象。敏感API fetch用cache:no-store。
- 仅roles/skills/documents/custom-tasks四种列表TTL15秒，返回已有缓存时后台更新。登录额外预取仅后三种。GET in-flight去重；审批/未决/执行状态、模型配置、资产健康、日志、核心文档正文、单资产记忆不做持久缓存。
- 写成功按资源精确失效列表及相关in-flight，旧读不得回填。核心资产文档每次打开新GET，因此备注更改/清空即时可见。
- 可见页定时更新；编辑列表控件后不周期重建，避免丢绑定/选择，重新进入页面或主动刷新再重载。后台失败明确状态提示，不以缓存伪装成功。角色输入、模式、执行账号不因列表后台更新重建。
- 性能口径：同Node真实组件Skills→定制任务→文档连续3轮，原15个GET、新7个GET（其中核心清单每轮均读取）。不是浏览器感官耗时结论。真实.94两次GET小样本仅作可复算参考，不据此声称后端延迟降低。
