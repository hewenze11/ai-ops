# 开发基线和阶段验收

用户已授权正式开始；所有开发由当前助手亲自完成，不调用开发子Agent。

## P0：执行协议纵向预览（当前实现范围）
- 后端角色/资产/账号快照、单命令任务、持久化队列、事务审计。
- Linux Agent 原生用户执行、有限输出、超时、崩溃未知、结果重试。
- 两仓独立 CI、容器镜像、真实测试机联调。
- 通过后只称“执行底座预览”，不能称后端完成。

## P1：完整后端执行可靠性
- 多步骤任务与父会话/轮次模型；当前 Task 是单操作，不等于完整角色轮次。
- Agent 注册心跳/重连、任务租约观测、未知结果人工确认、取消与cgroup清理。
- 完整输出文件归档、流量/磁盘限制、备份恢复、敏感信息清理、凭据轮换。
- SSH Connector，资产接入方式二选一。
- 协议冻结、跨版本兼容测试、安装/升级流程。

## P2：模型与角色后端
- 优先完成OpenClaw源码、许可证和裁剪验证，再决定集成边界；不要把Python执行底座误称为整个编排选型。
- 聚合站基础地址/模型/工具调用验证；低成本受控调用，不从模型上下文读取Key。
- 角色串行多步骤工具循环，本轮授权固定且服务端持有，确认/取消控制通路。
- 全量接口文档/核心文档注入、上下文预算可视、文档写入规则。
- 日记忆全文/压缩/梗概、旧记忆查询，原始审计独立保存。
- 本地Skills管理与准确注入位置；告警提示词/账号/角色配置与日志。

## P3：后端联调达标后开发Web和渠道
- 聊天/角色/账号标签/资产备注/任务/审计。
- 文档记忆编辑、Skills管理和触发器配置。
- 飞书、微信共享角色记忆；具体接入需验证。
- 商城本期不实现，仅预留主服务对接边界。

总预算维持3–4周基础内测、8–12周目标版；属于初步估计，依据真实技术验证更新。CI时间、账号审批和用户验收不可视作AI代码生成时间。每次工作以Git提交、自动测试和真实环境结果留证，不承诺在无运行会话时自动持续开发。
