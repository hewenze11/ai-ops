# 上手清单：从零到陌生人可用（4 个真实动作）

更新：2026-10-05。这不是开发任务清单（那些在 ROADMAP.md），而是一页**你本人**要在
真实的机器/账号上动手的事。所有代码侧的准备都已经做完，剩下的是只有账号持有人
才能做的外部动作。按顺序做，每步都有"做完怎么验证"。

---

## 前置：你需要的三台机器

- **1 台"控制机"**：跑主服务（AI 的大脑 + 控制台 + 网页对话）。建议 2C4G 以上、有公网 IP 或内网可达。
- **1 台"执行机"**：被 AI 操作的机器，安装执行端 Agent。可以就是控制机自己（用"本机纳管"），也可以另开一台。
- **1 台"你日常用的电脑"**：用来开浏览器访问控制台、看网页对话。任何能上网的电脑都行。

> 三台机器如何搭，`deploy/README.md` 有一步一命令的说明；主服务与执行端的安装脚本
> 都是一行 `curl | bash`（前提是下面第 1 步已完成）。真正卡人的只有第 1 步。

---

## 动作 1：把两个镜像包改成 public（**只有你能做**，必须最先做）

**为什么**：一键安装脚本要从 GHCR 匿名拉取镜像。若包是 private，陌生人执行安装
命令会得到 `401 unauthorized`，安装直接失败。这会让"5 分钟上手"落地页的
`curl | bash` 变成一句空话。

**怎么做**（只能网页操作，API 改不了——这是 GitHub 对用户级包的限制，我们已确认）：

1. 打开 https://github.com/users/hewenze11/packages/container/ai-ops/settings
2. 页面底部 "Danger Zone" → **Change visibility** → 选 **Public** → 输入包名确认。
3. 同样的操作对第二个包再做一遍：
   https://github.com/users/hewenze11/packages/container/ai-ops-agent/settings

**做完怎么验证**（在你的电脑上，不登录任何账号）：

```bash
docker logout ghcr.io 2>/dev/null   # 确保是匿名
docker pull ghcr.io/hewenze11/ai-ops:latest
docker pull ghcr.io/hewenze11/ai-ops-agent:latest
```

两条都能下载成功 = 完成了。若还报 `unauthorized`，回第 1 步检查是否真的改成了 Public
（有时会漏点第 2 个包）。

> 注：`ai-ops-site` 这个包已经是 public（之前已确认匿名可拉），无需再动。

---

## 动作 2：在某台机器上跑一遍"全新安装"（**你自己体验一次**）

**为什么**：你是产品的第一个用户，得亲眼看到"一行命令装好"。这一步同时验证动作 1
真的生效了。

**怎么做**（在控制机上，以 root 或 sudo）：

```bash
curl -fsSL https://raw.githubusercontent.com/hewenze11/ai-ops/main/deploy/install-control.sh | bash
```

装完脚本会打印一个**配对码**和一个控制台地址。按屏幕提示打开控制台，用配对码
进入。接着在执行机上装执行端：

```bash
curl -fsSL https://raw.githubusercontent.com/hewenze11/ai-ops/main/deploy/install-agent.sh | bash
```

（跨主机的执行端要用 https 配对码——`install-control.sh --public-url https://你的域名`
生成；同机安装用默认的 `http://127.0.0.1` 即可。）

**做完怎么验证**：在控制台"聊天"页对着某个角色说一句"帮我看下这台机器上 `id -un`"，
如果 AI 回话并真的执行了、给出真实账号名，就是通了。

**连不上怎么排查**：`deploy/README.md` 末尾有"常见失败"一节（镜像 401 / 端口不通 /
配对码超时各有对应说明）。

## 动作 3：配一个真实的告警外推 + 控制台链接（**让你亲手收到一条**）

**为什么**：这是产品的"第二棒"卖点，你要在有手机在手上的时候，亲眼看一条结论
推到 IM 里、并且能从里头点回控制台。

**怎么做**（控制台 → "调度与触发 → 告警外推"）：

1. 在飞书/钉钉/企微任一群里加一个自定义机器人，复制它的 Webhook URL。
2. 填进"Webhook 地址"；**"控制台链接"填你控制台的对外地址**（例如
   `https://你的域名` 或 `http://你的内网IP:8765`）。
3. 点"发送测试"——手机上应该收到一条测试推送，尾部带"查看 / 继续对话"链接。
4. 点那个链接——浏览器应打开控制台并切到聊天视图。

**做完怎么验证**：手机收到测试消息、点链接能跳进控制台，两步都成 = 完成了。

## 动作 4：给官网填真实内容（**产品"有货"的最后一块**）

**为什么**：官网的架构、支付、Skills 下发、课程播放器都做好了，但**视频地址是空的**——
播放器会显示"尚未配置视频地址"。填上真实视频，官网才算能卖给陌生人。

**怎么做**：

1. 录/处理好第一门前几节视频，拿到可播放的 URL（`.mp4` 直链，或 `.m3u8` 的 HLS 地址，
   或 B 站/腾讯云点播的嵌入地址）。
2. 按 `projects/ai-ops-site/docs/videos.md` 的说明，把 URL 填进对应课节。
3. 至少把"5 分钟上手"那一节填成**真实可播**——这是陌生人第一个会点的东西。

**做完怎么验证**：注册一个**新**账号 → 购买（当前是模拟支付）→ 点开课程 → 视频能真播。

> 说明：模拟支付会把订单标成 `provider=simulated`、不真扣款。接真实网关是后续动作，
> 不在本清单里（那要你去申请商户号）。本清单只要求"内容能播、流程能走通"。

## 顺序与预估

| 顺序 | 动作 | 谁能做 | 大概耗时 |
|---|---|---|---|
| 1 | 两个 GHCR 包改 public | 只有你 | 5 分钟 |
| 2 | 全新装一遍并体验 | 你 | 30–60 分钟 |
| 3 | 配真实告警外推 + 链接 | 你（手机在手） | 30 分钟 |
| 4 | 填真实视频 | 你 | 取决于录视频 |

**做完 1 和 2，产品就能被陌生人装上跑起来；做完 3 和 4，就能被陌生人用起来并买单。**
